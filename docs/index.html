Overview

UAKS is a technical knowledge storage and retrieval system based on atomic knowledge principles. It preserves source evidence, primary atoms, and derivative analytical atoms as distinct layers.

Quick Start

# Show pipeline status
python scripts/pipeline.py status

# Ingest a source file
python scripts/pipeline.py ingest path/to/file.txt

# Assemble atoms for a query
python scripts/pipeline.py assemble "knowledge atoms"

# Run tests
pytest tests/ -v

REST API

# Start API server (requires Flask)
python scripts/api_server.py

# Available endpoints:
# GET /status           - Pipeline status
# GET /atoms            - List atoms
# GET /atoms/       - Get specific atom
# POST /assemble        - Assemble atoms for query
# GET /graph            - Graph statistics
# GET /search?q= - Search atoms
